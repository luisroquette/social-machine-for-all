# Contributing to Social Machine for All

Thanks for helping make the template useful for more teams.

## Before opening a pull request

1. Keep changes brand-neutral. Company names, credentials, account handles and
   workspace IDs do not belong in the public template.
2. Put optional behavior behind workspace settings or feature flags, disabled by
   default.
3. Add or update focused tests when behavior changes.
4. Run `npm test`, `npm run build`, and `npm run audit:public-release`.

## Good first contributions

- Better onboarding and documentation
- More reusable platform adapters
- Safer defaults and test coverage
- Accessibility and dashboard improvements
- New provider integrations that remain optional

## Security

Do not open a public issue for a vulnerability or an exposed credential. Follow
[SECURITY.md](SECURITY.md) instead.
