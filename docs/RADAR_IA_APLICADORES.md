# RADAR IA — Camada Aplicadores / Workflow Builders

> **Propósito:** Monitorar criadores técnicos que demonstram aplicação prática de IA em workflows reais (não análise de mercado, não pesquisa acadêmica, não cobertura jornalística — construção).

> **Como essa camada se distingue das anteriores:** Camadas 1-10 cobrem onde a notícia NASCE (labs, C-levels, insiders, mídia). Camadas 11-17 cobrem quem AMPLIFICA. Esta camada cobre quem TRADUZ EM USO — demonstra o que a ferramenta faz na prática antes da maioria perceber.

> **Valor estratégico para newsletter:** sinal de adoção real, ângulo de aplicação vertical, oportunidade de seção "workflow da semana" que nenhuma newsletter gringa entrega com recorte BR.

---

## DNA do perfil-alvo

Um perfil pertence a esta camada se satisfaz pelo menos 4 dos 6 critérios:

1. Publica **demos de workflow** (vídeo, screenshot, diagrama) em vez de análise textual.
2. **Combina ferramentas** de forma explícita (padrão: "X + Y + Z + n8n").
3. Fala de **aplicação vertical** (DTC, ads, e-commerce, UGC, SaaS, design, educação).
4. Tem **alto engajamento consistente** (milhares de likes/RTs) sem ser lab nem C-level de empresa de IA.
5. Usa **formato estruturado** (listas com `→`, steps numerados, CTAs do tipo "comment X for the template").
6. Cita **ferramentas como instrumentos** (Cursor, Lovable, Bolt, n8n, Make, Zapier, Sora, Veo, Nano Banana, ElevenLabs, HeyGen, Claude Plugins, MCPs) em vez de discutir os labs por trás.

## Regra de scoring ajustada

Quando tweet vem de `layer = 18` e contém keyword de workflow showcase:

- Base: peso_fonte × multiplicador_keyword
- **Boost adicional de 1.3x se o tweet inclui mídia** (vídeo ou imagem — essencial para essa camada)
- **Boost adicional de 1.2x se texto menciona 2+ ferramentas do stack de referência**

Isso garante que um tweet de @mikefutia mostrando "Claude Plugins + n8n + Veo" em workflow DTC vai pontuar acima de uma thread analítica sobre o mesmo assunto.

## Diferencial editorial para a newsletter

Essa camada abre uma seção potente: **"Workflows da Semana"** — 3-5 workflows validados pelos aplicadores, com tradução para o recorte BR:

> "Mike Futia mostrou essa semana um pipeline de UGC com Sora 2 + Nano Banana + n8n. Custo estimado em BRL por video: ~R$ 4,50. Para DTCs brasileiras com catálogo de 50+ SKUs, substitui estúdio de produção nos primeiros meses."

Nenhuma newsletter gringa faz essa conta. Nenhuma newsletter BR tem radar para pegar o workflow no dia que sai.

## Manutenção

- **Revisar perfis semanalmente** nos primeiros 30 dias. Alguns vão se revelar hype sem substância e precisam ser rebaixados.
- **Monitorar emergentes** via cross-engagement: quando 3+ perfis layer 18 engajam com uma conta nova, investigar.
- **Desconfiar de crescimento explosivo**: perfil que vai de 10k → 200k em 60 dias é tipicamente otimizando para vanity metrics, não substância.
- **Sinal de queda**: quando perfil passa a repetir o mesmo workflow com ferramentas diferentes (tradução de hype), baixar peso.
